# Consonant gradation (k-p-t-vaihtelu) — Days 3, 6 · Kappaleet 2–3

The consonants **k, p, t** in the last syllable often change when you add an ending.
There is a **strong** grade and a **weak** grade.

## The changes

| Strong | Weak | Example (strong → weak) |
|---|---|---|
| kk | k | pankki → pankissa |
| pp | p | kauppa → kaupassa |
| tt | t | konsertti → konsertissa |
| k | – | Turku → Turussa |
| p | v | leipä → leivän |
| t | d | katu → kadulla |
| nk | ng | Helsinki → Helsingissä |
| mp | mm | kampa → kamman |
| lt | ll | ilta → illalla |
| nt | nn | ranta → rannalla |
| rt | rr | kerta → kerran |

## When is it weak? (nouns)

The weak grade usually appears when the syllable becomes **closed** (ends in a consonant):

- genitive **-n**: *katu → kadun*
- place endings **-ssa, -sta, -lla, -lta, -lle**: *kauppa → kaupassa*
- plural **-t**: *lippu → liput*

It stays **strong** in the partitive and illative: *kauppaa, kauppaan*.

## Verb type 1

Weak grade in **minä, sinä, me, te** and in the negative. Strong in **hän** and **he**.

| | nukkua (sleep) | ottaa (take) | lukea (read) |
|---|---|---|---|
| minä | nukun | otan | luen |
| sinä | nukut | otat | luet |
| hän | nukkuu | ottaa | lukee |
| me | nukumme | otamme | luemme |
| te | nukutte | otatte | luette |
| he | nukkuvat | ottavat | lukevat |
| negative | en nuku | en ota | en lue |

Verb types 3 and 4 work the **other way round** (Day 19): the basic form is weak and
*minä* is strong — *tavata → tapaan*, *ajatella → ajattelen*.
