# Ordinal numbers, dates and postpositions — Day 18 · Kappale 8

## Ordinal numbers

| | | | |
|---|---|---|---|
| 1. ensimmäinen | 6. kuudes | 11. yhdestoista | 20. kahdeskymmenes |
| 2. toinen | 7. seitsemäs | 12. kahdestoista | 21. kahdeskymmenesensimmäinen |
| 3. kolmas | 8. kahdeksas | 13. kolmastoista | 30. kolmaskymmenes |
| 4. neljäs | 9. yhdeksäs | 17. seitsemästoista | 31. kolmaskymmenesensimmäinen |
| 5. viides | 10. kymmenes | 19. yhdeksästoista | |

In writing, an ordinal is a number with a dot: **17.** = seitsemästoista.

## Dates

**ordinal + month in the partitive** (-ta/-tä):

- 17.10. → *seitsemästoista lokakuuta*
- 5.6. → *viides kesäkuuta*
- 24.12. → *kahdeskymmenesneljäs joulukuuta*

*Mikä päivä tänään on? — Tänään on seitsemästoista lokakuuta.*

Finnish writes dates **day.month.year**: 17.10.2026.

## Postpositions

They come **after** a word in the **genitive**:

| Postposition | Meaning | Example |
|---|---|---|
| vieressä | next to | pankin vieressä |
| edessä | in front of | talon edessä |
| takana | behind | koulun takana |
| välissä | between | kirjaston ja pankin välissä |
| lähellä | near | aseman lähellä |
| alla | under | pöydän alla |
| päällä | on top of | pöydän päällä |

## Giving directions

*Se on kulmassa.* (It's on the corner.)
