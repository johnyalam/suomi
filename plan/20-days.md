# 🗓️ 20-day plan — Suomen mestari 1 (Gehring & Heinzmann, Finn Lectura 2020)

Each day = **book pages → grammar → new words → quiz → sentences → commit**.
Start every day with `npm run day N`. Page numbers are the ones printed in the book (sivu).

## Week 1 — Basics (Kappaleet 1–3)

### Day 1

**Kappale 1: *Hei ja tervetuloa!*** · pages 10–13, 16 · Greetings and introducing yourself

- [ ] 📖 **Book:** pages 10–13, 16 — read the text, then do the exercises
- [ ] 📐 **Grammar:** Personal pronouns (minä, sinä, hän, me, te, he) and the verb olla (to be) → [`grammar/pronouns-olla.md`](../grammar/pronouns-olla.md)
- [ ] 📝 **Words:** 15 in [`vocab/day-01.csv`](../vocab/day-01.csv) — minä, sinä, hän, me, te, he, tervetuloa, hauska tutustua…
- [ ] 🎯 **Quiz:** `npm run quiz -- --day 1`, then add `--reverse`
- [ ] ✍️ **Sentences:** Introduce yourself in 3 sentences: name, where you live, that you study Finnish.
- [ ] 📈 **Track:** `npm run progress` → commit `day 01: greetings and introducing yourself`

Model sentences:

> Hei! Minä olen ___.  
> Hauska tutustua.  
> Mitä kuuluu? Kiitos, hyvää.  
> Minä olen suomen kurssilla.  
> Hän on opettaja.
